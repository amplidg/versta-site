# Ilustrações

Estilo: aquarela com textura de papel; paisagens amplas (montanhas, névoa,
florestas, lagos) e cenas humanas, em tons de verde, pêssego e azul claro.

A lista completa, com o nome de arquivo, o texto alternativo e a descrição de
cada ilustração, está em `data/imagens.ts`. Para ativar uma ilustração:

1. salve o arquivo aqui com o nome indicado (formato `.webp`, ~2000 px de largura);
2. em `data/imagens.ts`, mude `pronta` para `true` naquela entrada.

Enquanto `pronta` for `false`, o site mostra um placeholder com a legenda.
